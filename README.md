## 🎯 The Problem
Small development teams and solo founders ship fast but frequently miss security regressions, exposed API secrets, race conditions, or unhandled exceptions. Senior engineers spend 5-10 hours weekly reviewing routine pull requests instead of building high-impact features.

## 💡 The Solution
A zero-dependency, automated code review engine that triggers on pull requests, analyzes git diffs against security (OWASP Top 10) and reliability heuristics, and generates structured constructive findings with suggested code fixes.

## 🚀 Quickstart

### 1. Installation
```bash
git clone https://github.com/Arnoldlarry15/ai-pr-code-reviewer.git
cd ai-pr-code-reviewer
pip install -e .
```

### 2. Run the Standalone Demo
```bash
python demo.py
```

### 3. Run the Test Suite
```bash
pytest tests/
```
